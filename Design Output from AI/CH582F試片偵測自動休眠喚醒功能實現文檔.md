# CH582F 試片偵測自動休眠與喚醒功能實現

## 功能概述
本實現為 CH582F 微控制器添加了智能的試片管理功能：
1. 當試片拔出時，系統自動進入低功耗休眠模式
2. 在休眠狀態下通過 GPIO 中斷偵測試片插入
3. 試片插入後自動喚醒並恢復正常工作

## 實現的主要功能

### 1. 試片拔出檢測與自動休眠
- 在 `StripDetect_PeriodicCheck()` 函數中增加了試片拔出偵測邏輯
- 當兩個偵測引腳 (Pin3 和 Pin5) 都變為高電位時，判斷試片已拔出
- 拔出後自動：
  - 關閉 V2P5_ENABLE 停止對 CH32V203 供電
  - 關閉 T3 電極 (T3_IN_SEL = HIGH)
  - 啟動延遲 500ms 後進入休眠模式的任務

### 2. GPIO 中斷喚醒配置
- 新增 `StripDetect_ConfigureWakeupInterrupt()` 函數
- 配置 PA15 (Strip_Detect_5) 和 PB11 (Strip_Detect_3) 為下降沿中斷
- 使能對應的 GPIO 中斷以支持休眠喚醒

### 3. 休眠模式管理
- 新增 `StripDetect_EnterSleepMode()` 函數
- 在進入休眠前：
  - 停止定期檢查任務
  - 配置 GPIO 中斷喚醒
  - 確保外設處於低功耗狀態
- 調用 `CH58X_LowPower()` 進入深度休眠

### 4. 喚醒後恢復
- 新增 `StripDetect_WakeupFromSleep()` 函數
- GPIO 中斷服務程序自動調用喚醒處理
- 喚醒後：
  - 恢復 GPIO 為正常工作模式
  - 禁用中斷模式
  - 重新啟動定期檢查任務

## 修改的文件

### 核心文件
1. **StripDetect.c**: 主要的試片偵測邏輯
   - 添加了休眠相關的事件處理
   - 實現了完整的休眠/喚醒流程

2. **StripDetect.h**: 頭文件
   - 新增休眠事件定義 `STRIP_ENTER_SLEEP_EVT`
   - 添加新功能函數的宣告

3. **interrupt_handler.c**: GPIO 中斷處理 (新增)
   - 實現 GPIOA 和 GPIOB 的中斷服務程序
   - 處理試片插入的中斷喚醒

4. **interrupt_handler.h**: 中斷處理頭文件 (新增)

### 配置文件
1. **config.h**: 系統配置
   - 將 `HAL_SLEEP` 設置為 `TRUE` 啟用休眠功能

2. **SLEEP.c**: 休眠配置
   - 添加 GPIO 喚醒支持 (`RB_SLP_GPIO_WAKE`)

3. **peripheral_main.c**: 主程式
   - 包含中斷處理程序頭文件

## 工作流程

### 正常運作狀態
1. 系統啟動並初始化試片偵測模組
2. 以 100ms 間隔定期檢查試片狀態
3. 偵測到試片插入時：
   - 供電給 CH32V203
   - 延遲 1000ms 後發送插入消息給 MCU
   - 等待 MCU 回應試片類型

### 進入休眠狀態
1. 偵測到試片拔出 (Pin3 和 Pin5 都為 HIGH)
2. 關閉外部供電和 T3 電極
3. 延遲 500ms 確保所有操作完成
4. 配置 GPIO 中斷 (PA15, PB11 下降沿觸發)
5. 停止所有定期任務
6. 進入低功耗休眠模式

### 從休眠喚醒
1. 試片插入導致 GPIO 電平變化
2. 觸發 GPIO 中斷
3. 中斷服務程序調用喚醒處理函數
4. 恢復 GPIO 為正常模式
5. 重新啟動定期檢查任務
6. 恢復正常工作流程

## 功耗優化
- 休眠時僅保持必要的 GPIO 中斷功能
- 關閉所有不必要的外設供電
- 使用 CH582F 的深度休眠模式以達到最低功耗

## 安全性考量
- 在進入休眠前有 500ms 的安全延遲
- 多層級的狀態檢查確保系統穩定性
- 喚醒後完整恢復所有必要的系統狀態
